# Кредитный скоринг на данных Home Credit Default Risk

Модель, которая оценивает вероятность дефолта заёмщика, объясняет причины отказа
и (в планах) доступна через Telegram-бота.

**Статус:** в работе. Выполнены EDA, признаки из четырёх таблиц, сравнение трёх моделей, подбор
гиперпараметров и первый этап интерпретации (SHAP). Дальше: проверка роли защищённых признаков, доработка
причин отказа, дисбаланс и калибровка, бот, финальная оценка на hold-out.

## Данные

[Home Credit Default Risk (Kaggle)](https://www.kaggle.com/c/home-credit-default-risk): 307 511 заявок,
доля дефолтов около 8%. Используются четыре таблицы из семи:

| Таблица | Что содержит |
|---|---|
| `application_train` | основная заявка: доход, сумма кредита, занятость, внешние рейтинги |
| `bureau` | кредиты клиента в других бюро |
| `previous_application` | прошлые заявки в Home Credit |
| `installments_payments` | история платежей по прошлым кредитам (около 13.6 млн строк) |

Данные в репозиторий не входят: скачайте их с Kaggle в `data/raw/`.

## Как воспроизвести

Зависимости: `pandas`, `numpy`, `scikit-learn>=1.1`, `scipy`, `matplotlib`, `seaborn`, `lightgbm`,
`optuna`, `pyarrow`, `shap`, `joblib`.

Ноутбуки запускаются по порядку:

1. `01_eda_baseline` : EDA и baseline на основной таблице
2. `02_checks` : проверки гипотез по пропускам и дублям
3. `03_aggregates` : агрегаты из `bureau` и `previous_application`
4. `04_installments` : агрегаты из `installments_payments`, сохранение датасета
5. `05_models_comparison` : hold-out и сравнение трёх моделей
6. `06_optuna_lgbm` : подбор гиперпараметров LightGBM
7. `07_shap` : SHAP и причины отказа
8. `08_groups_and_protected` : состав групп причин, цена отказа от защищённых признаков
9. `09_explainable_model` : модель только из объяснимых признаков
10. `10_imbalance_calibration_threshold` : дисбаланс, калибровка, порог по стоимости ошибок

## Результаты

**Метрики.** Главная метрика: ROC AUC. Рядом Gini (= 2·AUC − 1) и KS, стандартные в банковском
скоринге, и PR AUC, более информативная при 8% положительного класса. Все сравнения идут на одних и тех же
фолдах стратифицированной 5-fold кросс-валидации, поэтому разницу между вариантами считаем попарно по
фолдам (`min diff`): если она положительна на всех фолдах, улучшение не случайно.

### Лесенка улучшений признаков (весь train, 5-fold CV, ROC AUC)

| Шаг | LogReg | LightGBM |
|---|---|---|
| Сырые признаки основной таблицы | 0.7470 | |
| + очистка аномалий | 0.7483 | |
| + доменные признаки | 0.7503 | |
| Основная таблица, без дублей жилья | 0.7504 | 0.7655 |
| + `bureau`, `previous_application` | 0.7630 | 0.7805 |
| + `installments_payments` | 0.7711 | **0.7864** |

### Сравнение моделей (dev = 80% train, 5-fold CV, OOF-метрики)

| Модель | ROC AUC | Gini | PR AUC | KS | Время CV, с |
|---|---|---|---|---|---|
| Random Forest | 0.7637 | 0.5274 | 0.2482 | 0.3948 | 2633 |
| Logistic Regression | 0.7700 | 0.5400 | 0.2513 | 0.4067 | 178 |
| LightGBM | 0.7842 | 0.5684 | 0.2740 | 0.4295 | 451 |
| **LightGBM, подобранные параметры** | **0.7872** | **0.5744** | **0.2777** | **0.4333** | |

Цифры двух таблиц несопоставимы напрямую: во второй модель обучается на 80% данных. Оценка на hold-out
будет выполнена один раз, после принятия всех решений (см. «Что дальше»).

## Ход работы и выводы

### 1. EDA и baseline на основной таблице

- **Пропуски.** В 41 колонке из 122 пропусков больше 50%; в основном это блок характеристик жилья
  (`COMMONAREA`, `LIVINGAPARTMENTS`, `FLOORSMIN` и др.).
- **Дубли в блоке жилья.** Каждая характеристика представлена тремя версиями (`_AVG`, `_MODE`, `_MEDI`),
  корреляция между ними 0.97 – 0.994. Оставляем только `_AVG` (28 колонок удалено). На AUC это почти не
  влияет (0.7503 → 0.7504), но убирает мультиколлинеарность и размазывание вклада по трём колонкам при
  интерпретации.
- **Заглушка в стаже.** `DAYS_EMPLOYED = 365243` встречается у 18% клиентов, почти все они пенсионеры
  (55 352 из 55 374). Дефолт у этой группы 5.4% против 8.7% у остальных. Поэтому значение заменяется на
  NaN, а факт заглушки сохраняется отдельным флагом. После очистки корреляция `DAYS_EMPLOYED` с таргетом
  меняется с −0.045 на +0.075: заглушка скрывала реальную зависимость.
- **Сильнейшие признаки.** `EXT_SOURCE_1/2/3` (корреляция −0.155 … −0.179), затем возраст (−0.078).
- **Пропуск как сигнал.** Дефолт у клиентов с пропуском выше: `EXT_SOURCE_1` 8.5% против 7.5%,
  `EXT_SOURCE_3` 9.3% против 7.8%, `COMMONAREA_AVG` 8.6% против 6.9%. Если в блоке жилья больше 10 пропусков
  (половина выборки), дефолт 9.2% против 6.8 – 7.3% у остальных. Для логрега отдельный признак «число
  пропусков» не нужен: индикаторы пропусков уже есть в пайплайне.
- **Структурные пропуски.** `OWN_CAR_AGE` пуст у 100% клиентов без машины и у 0% с машиной. Это «признак
  неприменим», а не «данные не собрали».
- **Доменные признаки** (`CREDIT/INCOME`, `ANNUITY/INCOME`, `EXT_SOURCE_MEAN` и др.) дают логрегу
  +0.0032 AUC против сырых признаков (прирост положителен на всех 5 фолдах, минимум +0.0028).
  Для бустинга они оказались полезнее: `EXT_SOURCE_MEAN` стал самым важным признаком модели (15.4% gain),
  а `CREDIT_TERM` и `CREDIT_GOODS_RATIO` вошли в топ-10.

### 2. Агрегаты из `bureau` и `previous_application`

- **Покрытие.** История в бюро есть у 85.7% клиентов, прошлые заявки у 94.6%.
- **Отсутствие истории** по-разному связано с риском: без записей в бюро дефолт 10.1% (против 7.7%),
  без прошлых заявок в Home Credit 6.0% (против 8.2%). Поэтому для обеих таблиц добавлены флаги наличия
  истории.
- **Эффект.** Логрег +0.0126 AUC (0.7504 → 0.7630), LightGBM +0.0150 (0.7655 → 0.7805). Агрегаты несут
  сильный сигнал даже для линейной модели.
- **Что работает.** Самые заметные новые признаки отражают недавнюю кредитную активность
  (`BUREAU_DAYS_CREDIT_MEAN`, `BUREAU_LAST1Y_COUNT`) и прошлые отказы (`PREV_*REFUSED*`, особенно за последний
  год). Это согласуется с идеей «кредитного голода». Многие из них сильно коррелируют друг с другом.
- Все агрегаты считаются без использования `TARGET` и по истории до даты заявки, поэтому утечки таргета
  нет.

### 3. `installments_payments`

- Добавлены просрочки (DPD), досрочность, недоплаты, их динамика и те же показатели за последние 6 и
  12 месяцев.
- **Эффект.** LightGBM +0.0059 AUC (0.7805 → 0.7864, `min diff` +0.0041), логрег +0.0081
  (0.7630 → 0.7711, `min diff` +0.0069). Критерий включения в базовый набор был задан заранее
  (`min diff > 0` и средний прирост у LightGBM не меньше 0.003), и он выполнен с запасом.
- Признаки за последний год сильнее коррелируют с таргетом, чем те же показатели за всю историю
  (0.082 против 0.070): свежее поведение информативнее старого.
- Остальные три таблицы (`credit_card_balance`, `POS_CASH_balance`, `bureau_balance`) отложены как
  возможное расширение.

### 4. Hold-out и сравнение моделей

- Из train выделено 20% клиентов (стратифицированно, список ID сохранён в файл). Hold-out не используется
  ни для подбора модели, ни для подбора параметров, ни для порога: к нему обращаемся один раз, в конце.
- **LightGBM лучший по всем метрикам**: +0.0142 AUC к логрегу (`min diff` +0.0113) и +0.0205 к случайному
  лесу (`min diff` +0.0162).
- **Логрег стабильно лучше леса**: на каждом из пяти фолдов лес проиграл (разница от −0.0101 до −0.0029).
- **Время.** Лес в 15 раз медленнее логрега и в 6 раз медленнее бустинга (2633 против 178 и 451 с).
- Возможные причины слабости леса (гипотезы, не проверялись): на сотнях коррелированных признаков он
  хуже бустинга; категории закодированы порядковыми номерами; при `max_features="sqrt"` каждый сплит видит
  лишь малую долю признаков.
- Параметры случайного леса не подбирались, поэтому результат относится к одной конфигурации.
- Логрег остаётся как интерпретируемый baseline: он на 0.014 AUC слабее при обучении в 2.5 раза быстрее.
  Основная модель: LightGBM.

### 5. Подбор гиперпараметров LightGBM (Optuna)

- 40 испытаний (29 завершено, 11 обрезано pruner'ом), 3 фолда на 50% dev, `learning_rate=0.1`.
- **Честная оценка** (те же 5 фолдов, фиксированное число деревьев без early stopping): 0.7842 → 0.7872,
  то есть **+0.0030 AUC**, на каждом фолде от +0.0021 до +0.0039. Gini, PR AUC и KS тоже выросли.
- В протоколе поиска разница выглядела больше (0.7734 → 0.7813, +0.0079): база там была в невыгодных
  условиях, к тому же выбор лучшего из нескольких конфигураций по одним и тем же фолдам завышает
  результат. Настоящий прирост: +0.003.
- **Лучшая конфигурация проще стартовой:** `num_leaves=17` (было 31), `min_child_samples=114` (было 20),
  `colsample_bytree=0.36`, `reg_lambda=3.9`, `subsample≈1.0`, 714 деревьев при `learning_rate=0.05`.
  Модели помогает ограничение сложности.
- Лучшее значение найдено примерно к 12-му испытанию, дальше улучшения порядка 0.0003, то есть на уровне
  шума. Стартовые параметры были близки к оптимуму, а подбор дал небольшой, но стабильный выигрыш.
- Параметры сохранены в `models/lgbm_best_params.json`.

### 6. Интерпретация: SHAP и причины отказа (первая версия)

- **Метод.** TreeSHAP из LightGBM (`pred_contrib=True`) на случайной выборке из 20 000 клиентов dev; вклады
  измеряются в лог-шансах дефолта. Вклады признаков суммируются по смысловым группам (SHAP аддитивен):
  25 групп, правила в `src/explain.py`. Все признаки получили группу.
- **Главные признаки.** `EXT_SOURCE_MEAN` (5.2% суммарного |SHAP|) и `EXT_SOURCE_MIN` (4.1%) впереди; весь блок
  внешних рейтингов даёт 18.4%. Верх списка согласуется с gain-важностью (`CREDIT_TERM`, `CREDIT_GOODS_RATIO`,
  `BUREAU_DEBT_CREDIT_RATIO_MAX`).
- **Вклад связанных таблиц.** Признаки из `previous_application` дают около 18% суммарного |SHAP|, из `bureau`
  около 14%, из `installments_payments` около 10%, вместе примерно 42%. Ни один признак
  `installments_payments` не вошёл в топ-20 по отдельности: вклад размазан по десяткам коррелированных
  признаков. Поэтому показывать причины по отдельным признакам нельзя, нужна группировка по смыслу.
- **Пол и семейное положение.** `CODE_GENDER` на третьем месте по важности (3.2%), `NAME_FAMILY_STATUS` на
  13-м (1.9%); вся группа защищённых признаков (вместе с возрастом и составом семьи) около 7%. В списке по
  gain пола не было. Модель опирается на эти признаки, хотя мы скрываем их из причин: фактическая причина
  решения и показываемая расходятся. Это требует отдельной проверки.
- **Скрыто от клиента** 10.7% вклада: защищённые признаки 7.0%, регион 2.0%, оценки окружения 1.1%,
  технические признаки заявки 0.7%.
- **Пример.** У клиента с вероятностью дефолта 76.4% топ-3 причины: низкий внешний рейтинг (+1.49), просрочки
  в других банках (+1.03), высокая сумма и платёж относительно дохода (+0.58).
- **Покрытие.** У каждого из 2000 самых рискованных клиентов выборки (верхний дециль) нашлось 3 причины.
  Топ-3 покрывают в среднем 66.9% положительного вклада (в знаменателе есть и скрытые группы).
- **Частота причин** в верхнем дециле: внешний рейтинг 91.6%, параметры кредита 44.2%, история предыдущих
  заявок 36.9%, занятость 34.8%, просрочки платежей 34.3%, задолженность в других банках 30.8%. Рейтинг
  почти всегда в топ-3, поэтому как объяснение он малоинформативен.
- **Найденные проблемы:**
  1. группа «Особенности истории предыдущих заявок» вторая по вкладу (16.1%) и слишком расплывчата для
     причины отказа;
  2. причины выдаются и клиентам с ничтожным риском (вклад +0.02), поэтому показывать их нужно только при
     отказе и выше минимального порога;
  3. группа «доход» весит 0.1%: доход модель использует через отношения (кредит/доход, платёж/доход), её
     стоит слить с параметрами кредита;
  4. формулировка группы «давность смены документов и телефона» сомнительна как причина для клиента.

### 7. Состав причин и роль защищённых признаков

**Что внутри групп причин** (направление: Спирмен между значением признака и его вкладом SHAP).

- **История предыдущих заявок** (самая расплывчатая группа, 16.1% вклада). Топ-10 признаков дают 66% группы и
  складываются в три смысловых блока:
  длительные сроки прошлых кредитов (`CNT_PAYMENT`, чем дольше, тем выше риск, около 17% группы);
  небольшие платежи и первоначальные взносы (`AMT_ANNUITY`, `AMT_DOWN_PAYMENT`, чем меньше, тем выше риск,
  около 18%); короткая или недавняя история в Home Credit (`DAYS_DECISION`, около 10%). Отдельно стоят
  отношение запрошенной и одобренной суммы (9%, чем выше, тем ниже риск) и даты закрытия прошлых кредитов
  (12%, чем позже, тем ниже риск).
- **Занятость.** Больше половины группы это категории `ORGANIZATION_TYPE` и `OCCUPATION_TYPE` (34% и 18%);
  `DAYS_EMPLOYED` 27% (короче стаж, выше риск); `EMPLOYED_BIRTH_RATIO` 8% (доля жизни на работе, чем выше,
  тем ниже риск; признак содержит возраст).
- **Параметры кредита.** Название «относительно дохода» подходило не всему: четверть группы это
  `CREDIT_GOODS_RATIO` (кредит выше стоимости товара, риск растёт), `CREDIT_TERM` (23%) имеет слабую связь
  (0.12), немонотонная зависимость.
- **Бюро.** Группа «активные кредиты» содержала признаки с противоположным эффектом: доля и суммы активных
  кредитов повышают риск, а общие суммы кредитов в бюро (`BUREAU_AMT_CREDIT_SUM_*`) снижают (связь от −0.56
  до −0.81): чем богаче история, тем ниже риск. Общие суммы выделены в отдельную группу.
- **Контакты и документы.** Признаки `DAYS_ID_PUBLISH`, `DAYS_LAST_PHONE_CHANGE`, `DAYS_REGISTRATION`
  действуют в одну сторону: чем недавнее смена документа, телефона или регистрации, тем выше риск.
  `FLAG_DOCUMENT_*` (24% группы) технические и клиенту не показываются.

Группы пересобраны по этим наблюдениям (`src/explain.py`).

**Пол в данных.** В dev 65.8% женщин и 34.2% мужчин. Доля дефолтов у женщин 7.00% (161 887 клиентов), у
мужчин 10.14% (84 119), то есть в 1.45 раза выше.

**Цена отказа от защищённых признаков** (LightGBM с подобранными параметрами, те же 5 фолдов,
разница с полным набором попарно по фолдам):

| Набор признаков | ROC AUC | Gini | PR AUC | KS | diff AUC (mean) | min | max |
|---|---|---|---|---|---|---|---|
| Полный | 0.7872 | 0.5744 | 0.2777 | 0.4333 | | | |
| Без возраста | 0.7861 | 0.5722 | 0.2757 | 0.4314 | −0.0011 | −0.0018 | −0.0007 |
| Без пола и семьи | 0.7849 | 0.5697 | 0.2755 | 0.4302 | −0.0023 | −0.0028 | −0.0017 |
| Без пола, семьи и возраста | 0.7835 | 0.5670 | 0.2735 | 0.4284 | −0.0037 | −0.0041 | −0.0033 |

- Потеря стабильна: на всех фолдах AUC ниже. Для масштаба: весь выигрыш от подбора гиперпараметров был
  +0.0030.
- Пол и семья дают вдвое больше информации, чем возраст (−0.0023 против −0.0011); эффекты почти

- Без пола и семьи модель завышает риск женщин (7.3% при факте 7.0%) и занижает риск мужчин (9.3% при

  компромисс, и какой вариант справедливее, зависит от выбранного критерия.
- Отношение M/F сокращается с 1.85 до 1.56, но не исчезает: часть разницы отражает реальное различие

- Исключение возраста почти не меняет исходы по полу (1.83) и стоит 0.0011 AUC.
- Модель использует пол (и семью), хотя из причин мы их скрываем: показываемая причина отказа расходится с
  настоящей. Принцип для следующего шага: в модели остаются только признаки, которые можно показать клиенту.

### 8. Модель «только объяснимые признаки»

Принцип: в модели остаются только признаки, которые можно назвать клиенту как причину отказа. Тогда
показываемая причина совпадает с настоящей. Сравнение на тех же 5 фолдах, с теми же гиперпараметрами:

| Набор признаков | ROC AUC | Gini | PR AUC | KS | diff AUC (mean) | min | max |
|---|---|---|---|---|---|---|---|
| Полный | 0.7872 | 0.5744 | 0.2777 | 0.4333 | | | |
| Без защищённых (пол, семья, возраст) | 0.7835 | 0.5670 | 0.2735 | 0.4284 | −0.0037 | −0.0041 | −0.0033 |
| Только объяснимые (ещё без региона, окружения, технических) | 0.7830 | 0.5660 | 0.2736 | 0.4271 | −0.0042 | −0.0048 | −0.0038 |

- **Цена принципа 0.0042 AUC** (0.5% от значения), стабильно на всех фолдах. Это в 1.4 раза больше выигрыша от
  подбора гиперпараметров (+0.0030).
- Регион, оценки окружения и технические признаки вместе дают 4.8% суммарного |SHAP|, но их удаление сверх
  защищённых стоит всего 0.0005 AUC (среднее по фолдам; стабильность по фолдам отдельно не проверялась).
  Вероятно, их информация в основном дублируется другими признаками (гипотеза).
- Результат варианта «без защищённых» (0.7835) воспроизвёл результат из раздела 7 с точностью до четвёртого
  знака.

**Раскладка по группам после пересборки.** Расплывчатая группа «прочее по предыдущим заявкам» сократилась
с 16.1% до 0.5% вклада. Теперь вторая по вкладу объяснимая группа это просрочки платежей в прошлых кредитах
(8.6%). Из причин исключены (12.3% суммарного вклада): защищённые признаки 7.5%, регион 2.0%, технические
признаки 1.7%, оценки окружения 1.1%.

**Профили неоднозначных признаков** (средний вклад SHAP по квантилям значения):

- `CREDIT_TERM` (приблизительно обратен сроку кредита) действует немонотонно: средние значения
  (0.046 – 0.07) повышают риск (+0.09, +0.05), длинные и короткие сроки снижают (−0.04 и −0.07). Эффекты
  невелики, направление нельзя выразить одной фразой, поэтому группа названа нейтрально: «параметры
  запрашиваемого кредита (срок, сумма относительно стоимости товара)».
- `AMT_GOODS_PRICE`: дорогие товары (свыше 837 тыс.) снижают риск (−0.055), остальные слегка повышают.
- `BUREAU_DAYS_CREDIT_ENDDATE_MAX`: немонотонный, самый низкий риск при ближайшем оконча
